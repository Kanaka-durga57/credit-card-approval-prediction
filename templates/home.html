Credit Card Risk Prediction

AI-powered credit risk assessment using Machine Learning

About the Project

This application uses machine learning to analyze applicant information and estimate their credit risk based on historical credit data.

How It Works

1 Enter applicant details
2 Machine learning analyzes the data
3 View the predicted credit risk

Technology Used

Python Flask Pandas NumPy Scikit-learn Random Forest HTML CSS JavaScript
